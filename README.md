All themes follow a consistent design language:

```css

    --accent: #d4af37;          /* Premium gold accent */
    --accent-light: #f4d06f;    /* Light gold highlight */

    --text-secondary: #a0aec0;  /* Muted secondary text */
    --card-bg: rgba(15, 31, 56, 0.8); /* Glassmorphism cards */
}
